# 设置菜单说明

在待机界面按**MENU**打开应用菜单，选择**Settings**进入设置。在设置菜单里：

- **上/下键**在选项之间移动（最上层则是在7个分组之间移动）。
- **MENU**进入选中的分组，或开始编辑选中的数值。
- 编辑状态下，**上/下键**修改数值。
- **EXIT**逐级返回上一层。

电台上依次显示的7个分组是：**RADIO**、**AUDIO**、**DISP**、**KEYS**、**ANI**、**DIGI**、**SYSTEM**。

## RADIO（电台）

| 屏幕显示 | 含义 |
|---|---|
| `SQL` | 静噪等级，0–9。数值越大，需要越强的信号才能开噪音门。 |
| `STEP` | 调频步进，从2.5kHz到10kHz可选。 |
| `TOT` | 发射超时定时器。`0`=关闭；否则以15秒为一档递增（`1`=15秒……`12`=180秒）——超过这个时长会自动停止发射。 |
| `TDR` | 双守候：开启后同时监听两个VFO/信道，空闲时在两者间轮流切换。 |
| `SAVE` | 待机状态下的省电占空比。`0`=关闭；`1`–`4`档位越高省电越激进（两次接收检测之间关闭电路的时间更长——更省电，但收到信号的反应会稍慢）。 |
| `BCL` | 忙道闭锁：开启后，信道有信号（忙）时禁止发射。 |
| `TXINH` | 发射禁止：开启后完全禁止发射（仅接收）。 |
| `W/N` | 信道带宽：`WIDE`（宽带）或`NARROW`（窄带）调频。 |
| `PWR` | 发射功率：`HIGH`/`MID`/`LOW`。 |
| `R-CTC` | 接收亚音 |
| `T-CTC` | 发射亚音 |
| `SHIFT` | 相对接收频率的中继偏移方向：`OFF`（同频单工）/`+`/`−`。 |
| `OFFSET` | `SHIFT`为`+`或`−`时使用的偏移量（kHz）。 |
| `SCRM` | 语音反转扰频等级：`OFF`或预设`1`–`3`。通话双方要设成一样的档位才能听懂对方。 |
| `SCANMD` | 信道扫描的停止方式：`TIME`（短暂停留后继续扫描）、`CARR`（有载波时停留）、`STOP`（扫到第一个信号就停在那不动）。 |
| `RIT` | 接收微调（clarifier）偏移量，单位Hz，±1270Hz范围内以10Hz为步进。主要在USB模式下有意义。 |
| `CHDISP` | 信道显示方式：`FREQ`（频率）、`NAME`（信道名称）、`NAME+F`（名称+频率）。 |
| `BK-IN` | CW全/半双工插入：`OFF`、`SEMI`（键控间隙自动切回接收）、`FULL`。仅在CW模式下可调。 |

## AUDIO（音频）

| 屏幕显示 | 含义 |
|---|---|
| `BEEP` | 按键确认提示音，开/关。 |
| `VOX` | 声控发射：开启后可以用声音触发PTT，实现免提通话。 |
| `VOXLV` | VOX灵敏度，`1`–`9`（数值越大，越轻的声音也能触发）。 |
| `VOXDLY` | 停止说话后VOX继续保持发射的时长，`0.5S`–`2.0S`。 |
| `RTONE` | 类似1750Hz的中继开启音频率（4档预设）——长按分配给`TX TONE`功能的按键发送（见`KEYS`分组）。 |
| `STE` | 静噪尾音消除：开启后可以消除通话结束时那一小段噪声。 |
| `RPTRL` | 中继/挂起延迟：松开PTT后，电台等待多久才真正切回接收。`OFF`=立即切回；否则以100ms为步进。 |
| `ROGER` | 松开PTT时发出的通话结束提示音：`OFF`、`ROGER`提示音，或`MDC1200`信令音。 |

## DISP（显示）

| 屏幕显示 | 含义 |
|---|---|
| `ABR` | 背光自动关闭定时：`OFF`（常亮）或无操作`5S`/`10S`/`15S`/`20S`后关闭。 |
| `AUTOLK` | 按键自动锁定定时：`OFF`或无操作`5S`/`10S`/`15S`后锁定。 |
| `CONTR` | LCD对比度等级，`0`–`4`。 |

## KEYS（按键）

给每个可编程按键分配一个功能。以下6项共用同一份功能列表：`NONE`（无）、`WIDE/NAR`（宽窄带切换）、`MONITOR`（监听）、`MODE`（调制方式切换）、`TX TONE`（发送开中继音）、`FM RADIO`（收音机）、`SCAN`（扫描）、`POWER`（功率切换）、`LIGHT`（手电筒）、`SEARCH`（频率搜索）、`REVERSE`（收发反转）、`APRS TX`（APRS发信标）。

| 屏幕显示 | 含义 |
|---|---|
| `S1-SH` | 侧键1，短按。 |
| `S1-LG` | 侧键1，长按。 |
| `S2-SH` | 侧键2，短按。 |
| `S2-LG` | 侧键2，长按。 |
| `BND-SH` | BAND键（扫描键），短按。 |
| `BND-LG` | BAND键（扫描键），长按。 |

## ANI（自动识别码）

随发射一起自动发送的DTMF识别码/呼叫码。

| 屏幕显示 | 含义 |
|---|---|
| `ANI-TX` | 开启后，每次发射开始时自动发送一段DTMF识别码。 |
| `CALL` | 要发送哪个已存联系人的DTMF代码（从联系人列表中选择）。选`----`（无）时，即使`ANI-TX`开着也不会发送。 |

## DIGI（SSTV、APRS）

SSTV、APRS相关设置。

| 屏幕显示 | 含义 |
|---|---|
| `CALLSIGN` | 呼号，作为APRS信标的源地址以及SSTV发送的呼号。 |
| `SSID` | APRS SSID后缀，`-0`到`-15`（例如手持台常用`-7`）。 |
| `FREQ` | APRS信标的发射频率。 |
| `LAT` / `LON` | 信标里发送的固定台站经纬度（本机没有GPS，所以位置需要手动设置）。显示`----`表示未设置——经纬度未设置则不会发送信标。 |
| `PATH` | 数字中继路径：`W1-1,W2-1`（默认通用路径）/`WIDE2-2`/`ARISS`（用于卫星/ISS通联）/`DIRECT`（不经过数字中继）。 |
| `NAME-EN` | 开启后，会在信标注释开头加上设备名称（`DEVNAME`）。 |
| `DEVNAME` | `NAME-EN`开启时，附加在注释里的自定义设备/型号名称。 |
| `BATT-EN` | 开启后，信标注释里会包含当前电池电压。 |
| `COMMENT` | 附加在信标里的自由文本注释。 |
| `SYMBOL` | 信标在地图上显示的APRS符号：`PERSON`（人）、`HANDHELD`（手持台）、`CAR`（汽车）、`TRUCK`（卡车）、`BICYCLE`（自行车）、`HOUSE`（房屋/QTH）、`WEATHER`（气象站）、`DIGIPEATER`（数字中继台）、`HF_GATEWAY`（HF网关）、`BALLOON`（气球）、`AIRCRAFT`（小型飞机）。 |
| `POWER` | 专门用于APRS信标发射的功率：`LOW`/`MID`/`HIGH`。 |

## SYSTEM（系统）

| 屏幕显示 | 含义 |
|---|---|
| `FLOCK` | 发射频率锁定/频段规划：地区预设（`CE HAM`、`FCC HAM`、`GB HAM`、`CA HAM`）、固定频段（`400-430`、`400-438`）、免执照预设（`PMR446`、`GMRS/FRS`）、`ALL LOCK`（任何频率都禁止发射），或`UNLOCK`（硬件全范围——见[README](../README.zh.md)顶部的警告）。 |
| `BATCAL` | 电池电压校准：输入用万用表实测到的电池电压，用来修正屏幕上显示的电压读数。 |
| `BOOTSCR` | 开机时显示的内容：`NONE`（无）、`VOLT`（电池电压）、`MSG`（两行自定义文字）、`LOGO`（自定义位图——见[导入开机图片](Boot-Logo.zh.md)）。 |
| `BOOTSND` | 开启后，开机时会播放一段开机音乐。只有`BOOTSCR`不是`NONE`时才能选。 |
| `VER` | 显示固件版本 |
| `RESET` | 恢复出厂设置。再按一次MENU确认——这会清空所有设置、信道，以及通过CPS写入的数据。 |
